# Hi, I'm Luca Varotto

M.Sc. Statistics candidate at the University of Padua, with a strong focus on Machine Learning and Data Science.

I like problems where a statistical model has to survive contact with real, messy data: text scraped from the web, experimental measurements, second-hand marketplace listings, tracking data from football matches. My M.Sc. thesis works on Markov processes over general state spaces to measure how dangerous a possession is in football.
